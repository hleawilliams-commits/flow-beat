## Install on the current USB

Use the existing repository in Community Mods. Publishing changes nothing on the deck by itself. Install one mod at a time between playback, retaining the previous package and verified USB backup. Reload interrupts playback.

The current Phase Strip and Grouped Panels folders were copied by hand and have no `.origin` repository metadata. The official installer refuses to adopt them in place. Do not fabricate that metadata. Grouped Panels is already the exact released 0.1.0, so leave it in place. Phase Strip 0.1.1 needs the native Remove then Install workflow, or a later backed-up USB staging update, before 0.1.2 can be used. Confirm it is enabled before Reload. MODS Shortcut is a new install.

## Explicit limits

USB 1/USB 2 buttons are deferred to the next update and are intended for the old WAVEFORM heading area. No placeholder browse buttons were published. FLOW Neon, native jog-key work and stems-engine experiments remain separate emulator work. This release makes no stems fix or Deck 2 phrase fix claim.

The latest [physical stems note](evidence/physical-stems-2026-10-17/README.md) confirms Deck 4 has no decoded buffers. Measured memory requirements and the core’s failed-load cache support memory pressure followed by no retry as the leading cause. Existing Ogg files on USB still need decoding into working memory. The original refusal log is absent, and full Ogg decoding was not tested. The core patch remains emulator-only and preserves the memory safety reserve.

See [publication receipt](evidence/publication-2026-10-17/receipt.json) for package hashes and exact revisions. No physical core, firmware, USB content or settings were changed during this GitHub publication.
