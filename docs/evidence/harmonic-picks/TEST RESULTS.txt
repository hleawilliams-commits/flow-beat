Initial emulator failure corrected: control transport frames are padded to 152 bytes,
whereas core input frames can be shorter. Final code requires at least 98 bytes (the CRC
protected mixer frame), not exactly 152. The focused test now exercises a 98-byte frame.

Scope and limits:
- This is a shortcut to the existing native browser, NOT the complete automatic one-button
  MASTER matching feature originally envisioned. The user sets BPM/KEY/MASTER and enables
  Track Filter first. PICKS preserves filter state, source, category and other conditions.
  If the filter is off or another category is selected, PICKS opens that current view.
- Custom harmonic/acapella suggestions remain in Mod Menu and remain read-only.
  No custom suggestion-to-native-track transfer or automatic acapella loading exists.
- Native matching, available files and loading rules belong to EP147. The emulator has a
  full metadata library but only a few copied audio files; playback proof uses Access Denied.
- No firmware hooks, library writes, simulated LOAD/PLAY or pointer taps in the package.
- Physical board/USB: no changes, no installation, no physical test.
- GitHub: no push or release publication. Local release entry URLs are publication targets only.
- No verification that native filtering follows Key Shift; the custom page uses stored keys.
