# Immutable module and generated-range attribution fixture

This separately versioned offline C/Linux composition connects permanent module ownership records to the retained generated-range reader and the exact SDK fault-selection body. It implements the [reviewed module attribution plan](../activation-module-attribution-plan/README.md). Ownership identifies a recorded address owner; it does not establish fault causation. All live gates remain **CLOSED**.

The first complete runtime matrix and independent retained-byte audit pass. The evidence remains limited to this offline composition.

## Implemented composition

Four fixed slots contain an immutable original index, process identity, canonical zero-padded 33-byte ID and checked half-open min/max PT_LOAD envelope. A release store publishes each completed payload. Readers acquire slots independently, skip unpublished holes and scan in original index order. Separate writer-only state makes staging and commitment one-use. Mutable permissions, sessions and hook counts remain in the locked lifecycle controller.

For the two fixed authored roots, validated loader provenance publishes ownership before a later capability, descriptor or init refusal. This does not grant hook permission. The raw successful query and the deliberately refused consumed result remain separate, with one publication veto. Successful handles remain retained after later refusal. Constructors execute before publication; the unassigned root/dependency objects do not receive a fabricated Community identity.

At each numeric address, module envelopes are checked first, including gaps and non-executable PT_LOADs. The unchanged C `rc_lookup` is consulted only after a module miss and attributes only generated instruction ranges. A generated Community owner resolves its complete copied process identity and all 33 ID bytes to exactly one committed module. Core, absent or ambiguous identity returns no Community index, allowing the consumer's LR/frame fallback. Binding numbers are never treated as module indices. Synthetic cases explicitly permit a later module envelope to mask earlier generated instructions or own a generated literal address.

The exact 962-byte `cm_blame_fault` body is retained under scoped aliases. It still checks PC, then LR, then at most sixteen frame records; checks each frame return address before the nonincreasing-frame break; preserves the original local volatile once guard; performs the original persistence-call sequence; and returns a stable permanent ID. Integer-keyed frame cells and modeled open/write/fsync/close providers replace its native dependencies. No native frame dereference, installed signal handler or real crash-file persistence is exercised.

The fixed host targets, replacements, strong aligned plain original slots, generated receipt reader and internal metadata-before-original-before-redirect cut remain unchanged. The fixed authored DSOs provide actual loader, constructor, entry/init and ordinary builtin caller-RA observations. Selected new cases install into authored host targets to connect retained emission receipts to the new attribution path. Patched targets, replacements and emitted instructions are never invoked; all eight authored invocation counters are checked and retained.
