# Inactive supervisor observation and terminal admission

This separate successor binds the frozen actual-child observation journal to
the exact port retained by the existing startup/lifecycle graph. Known loss
closes terminal port admission before polling; newly returned error/exit,
poll unwind, normal scope end and scope unwind also latch it. After finding
the owner, missing/busy/poisoned child access records a separate refused-scope
latch receipt. No new resource owner or production main selection is added.

The latch uses the existing terminal atomic stop and nonblocking wake. It
applies across port clones and can stop the local worker. It neither stops the
child nor joins the worker, closes the producer synchronously, or cancels work
already dispatched. A late ACK/settings write can still complete. Existing
explicit finish retains the actual resources and joined accounting.

Two fresh offline matrices each passed seven new integration selectors and
four compiled strict controls. One production-configuration check compiled the
inactive composition in the pinned actual az-preview crate. The independent
repeat omitted that check and executed no inherited suites. The fixtures use
real host child processes, the existing source graph and private settings files
with a modeled backend; no emulator or physical deck was started or contacted.
